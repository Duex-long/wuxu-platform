# 产品范围摘要

物序用于登记和审计个人物品，核心信息包括名称、两级类目、数量、单位、存放位置、图片、保质期和物品状态。

物品状态包括：

- `IN_USE`：使用中
- `UNUSED`：未使用
- `DAMAGED`：已损坏
- `CONSUMED`：已消耗

用户端负责个人物品登记、查找和状态维护；管理后台负责全局类目、存放位置以及授权范围内的查询和统计。

## 已实现范围

- 大类目和小类目由管理员统一维护，普通用户登记物品时只能从后台配置的类目中选择；物品保留类目名称快照。
- 图片按用户选择顺序关联到物品；每个文件独立校验，失败不会影响其他文件。
- 图片文件保存在 S3 兼容对象存储，SHA-256 等元数据与业务文件分开保存。
- 用户统计包含记录数、数量、状态、类目、30 天内到期和已过期。
- 管理后台只读展示跨用户统计与物品列表，不修改用户物品；管理员可维护全局两级类目和存放位置。
- 管理后台的数据中心、类目管理和位置管理分别使用独立页面，避免管理表单与统计查询混在同一页面。
- 存放位置由管理员创建，包含名称、说明和必填照片；用户登记物品时只能选择已有位置。
- 用户端和管理后台都可以按位置查看其中的物品；非空位置禁止删除。
- 用户端首页作为功能入口，物品查找与新增为独立页面，并适配移动端操作和底部导航。
