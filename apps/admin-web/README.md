# Wuxu Admin Web

Vue 3 管理后台，已实现管理员登录、全局两级类目管理、带照片的存放位置管理、按位置查看物品、全局统计、状态与类目分布，以及按用户、名称、位置和状态进行跨用户只读查询。

数据中心、类目管理和位置管理使用独立页面：`/admin/`、`/admin/categories`、`/admin/locations`。共享侧边导航会标识当前页面，移动端保留可访问的顶部导航。

后台不会修改用户物品；物品保存类目名称快照，删除类目不会改写历史物品。位置内仍有物品时不能删除该位置。图片通过鉴权接口读取，不暴露对象存储地址。

开发环境请从 Monorepo 根目录运行 `docker compose up --build`，随后访问 http://localhost:5174。
