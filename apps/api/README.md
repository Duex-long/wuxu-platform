# Wuxu API

NestJS 后端应用目录。

MySQL 保存用户与身份数据，MongoDB 保存类目和物品领域数据，对象存储保存图片文件。

当前已实现：

- MySQL 用户与开发账号初始化
- JWT 登录和角色守卫
- 管理员维护全局两级类目，普通用户只读选择，物品保存类目快照
- 管理员维护全局存放位置和位置照片，用户只能通过位置 ID 选择
- MongoDB 物品增删改查、状态变更历史和统计聚合
- 消耗品预计使用周期、日均计划消耗、进度计算和待检查筛选
- 单图独立上传、文件签名校验、S3 文件存储和 MongoDB SHA-256 元数据
- 管理员跨用户只读物品查询与全局统计
- MySQL、MongoDB 和 S3 兼容存储健康检查
- OpenAPI 文档

图片二进制与业务数据分离：对象存储保存原始文件，MongoDB 只保存归属、对象键、大小、MIME、SHA-256 和物品关联。多文件由用户端按原选择顺序，以最多 3 并发调用单文件接口。

存放位置是全局受控资源。位置照片为必填；普通用户可读取已关联的位置照片，但不能创建、修改或删除位置。位置内存在有效物品时，删除位置会返回冲突错误。

类目同样是全局受控资源。普通用户可以读取类目树，但创建、重命名和删除操作仅允许管理员执行；系统在没有可用类目时提供“未分类”兜底项。

开发环境请从 Monorepo 根目录运行 `docker compose up --build`。

完整的后端设计架构见 [`docs/backend-architecture.md`](../../docs/backend-architecture.md)。
